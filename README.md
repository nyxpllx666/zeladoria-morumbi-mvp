# zeladoria-morumbi-mvp
MVP web (Flask/Bootstrap) para centralização de demandas comunitárias e geração de relatórios - Associação de Moradores do Morumbi.

## Como executar localmente
1. Instale o Flask: `pip install flask`
2. Execute a aplicação: `python3 app.py`
3. Acesse `http://127.0.0.1:5000/`
